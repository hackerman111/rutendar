# Дизайн: Экспорт заметок в CLI и Inline-меню (День / Неделя / Месяц / Все / Выбранные)

## 1. Цель
Предоставить пользователю возможность экспортировать заметки с прикрепленными ссылками в структурированный Markdown (`.md`) документ как через быстрые команды CLI с фильтром по периоду (день, неделя, месяц, все), так и через интерактивное inline-меню с возможностью мульти-выбора заметок.

---

## 2. Формат экспорта (Markdown)
Экспортируемый файл представляет собой аккуратный Markdown-документ:
```markdown
# Экспорт заметок Rutendar
_Период: Неделя (01.09.2026 — 07.09.2026) | Всего заметок: 3_

---

## 01.09.2026 — Список покупок
Купить молоко, хлеб и чай для офиса.

### Ссылки:
- [Магазин](https://example.com/shop)

---

## 02.09.2026
(Заметка без заголовка)
Текст заметки...
```

---

## 3. CLI: Однострочные команды
Флаг для экспорта заметок:
```bash
rutendar --export-notes [day|week|month|all] [--file <путь>]
# или короткие алиасы:
rutendar -n -e [day|week|month|all] [-o <файл>]
```
- Аргумент периода:
  - `day` (или `сегодня`, `день`) — заметки на сегодня.
  - `week` (или `неделя`) — заметки на текущую неделю.
  - `month` (или `месяц`) — заметки на текущий месяц.
  - `all` (или `все`) — все существующие заметки.
  - По умолчанию, если период не указан: `all`.
- Опция пути `--file` / `-o`:
  - Если путь указан (например, `--file ~/notes.md`), записывает в этот файл.
  - Если путь не указан, сохраняет в файл `notes_<период>_<дата>.md` в текущей директории и выводит путь в консоль.
  - Если указан `--stdout`, выводит сгенерированный markdown прямо в стандартный поток вывода.

## 4. Inline-меню заметок: интерактивный режим
Запуск:
```bash
rutendar --notes
# или коротко:
rutendar -n
# или:
rutendar notes
```
Открывает компактный терминальный интерфейс (`Viewport::Inline(10)`, аналогично `--task`):
- **Вкладки фильтров периода**: `[ День ] [ Неделя ] [ Месяц ] [ Все ]` (переключение по `Tab`).
- **Список заметок**:
  - Чекбокс выбора для экспорта: `[ ]` или `[*]`.
  - Дата заметки: `01.09`.
  - Заголовок (или первая строка текста, если заголовок пустой).
  - Индикатор прикрепленных ссылок (например, `[🔗 2]`).
- **Горячие клавиши в меню**:
  - `j` / `k` (или `↓` / `↑`) — навигация по списку.
  - `Space` — отметить / снять отметку с заметки для экспорта (`[*]` ↔ `[ ]`).
  - `Tab` — переключение фильтра периода (`День` → `Неделя` → `Месяц` → `Все`).
  - `a` — выбрать все заметки в текущем фильтре (или снять выбор со всех, если все уже выбраны).
  - `e` — **экспортировать**:
    - Если выбраны конкретные заметки (`[*]`), экспортирует только их.
    - Если ни одна не отмечена чекбоксом, экспортирует все заметки текущего фильтра периода.
    - Сохраняет в файл `notes_export.md` и выводит сообщение об успешном экспорте.
  - Ввод текста — мгновенная фильтрация списка по тексту/заголовку.
  - `Esc` / `q` — выход из меню.

## 5. Архитектура и хранилище
- В `src/storage/database.rs`:
  - Метод `Database::notes_on_date(date)` (уже есть `notes_between`).
  - Метод `Database::all_notes()` — получение всех заметок с их ссылками.
- В `src/cli/note_export.rs`:
  - Генератор Markdown из `&[Note]`.
  - Логика однострочного CLI-экспорта `run_notes_export(database, period, file_path, stdout)`.
  - Интерактивное inline-меню `run_notes_menu(database)`.
- В `src/cli/mod.rs`:
  - Регистрация команд `NotesMenu` и `NotesExport`.
  - Обновление справки `print_help()`.
