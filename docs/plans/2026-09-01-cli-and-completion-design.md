# Дизайн: CLI для rutendar (`--list`, `--add`) и автодополнение тегов и путей

## 1. Контекст и цели

Цель разработки:
1. Предоставить быстрый доступ к событиям календаря из терминала без необходимости запускать полноэкранный TUI.
2. Реализовать команду `rutendar --list` (`-l`), выводящую компактное интерактивное меню (inline viewport в стиле автодополнения zsh / fzf) с фильтрацией ближайших событий по периодам (день, неделя, месяц) и красивым выводом выбранного события в стандартный вывод.
3. Реализовать команду `rutendar --add` (`-a`) для интерактивного создания нового события из терминала (а также через CLI-флаги).
4. Добавить полноценное автодополнение тегов (по базе данных SQLite) и директорий (по файловой системе с раскрытием `~`) как в TUI-редакторе событий, так и при создании события в CLI.

---

## 2. Архитектура и структура модулей

Все новые возможности реализуются в рамках единого бинарника `rutendar` без добавления тяжелых внешних зависимостей, опираясь на уже используемые `ratatui` (0.29) и `crossterm` (0.28).

### Новые и измененные файлы:
- `src/completion/mod.rs` (или `src/completion.rs`):
  - Модуль автодополнения.
  - `complete_tags(&Database, prefix)`: дополнение `#тег` по префиксу.
  - `complete_directories(input_path)`: раскрытие `~`, поиск директорий в родительской папке, фильтрация по префиксу.
- `src/cli/mod.rs`:
  - Парсер аргументов командной строки (`--list` / `-l`, `--add` / `-a`, `--help` / `-h`).
  - Диспетчер выполнения CLI-режимов.
- `src/cli/list.rs`:
  - Интерактивный inline-виджет выбора событий (`ratatui::Viewport::Inline`).
  - Форматирование карточки события в stdout со стилизацией ANSI (важность, время, название, теги, описание, кликабельные ссылки, директория).
- `src/cli/add.rs`:
  - Пошаговый интерактивный опрос в терминале с автодополнением по клавише `Tab` (для тегов и путей).
  - Поддержка параметров командной строки `--title`, `--date`, `--time`, `--importance`, `--tags`, `--dir`, `--desc`.
- `src/app/state.rs`:
  - Добавление `pub path_suggestions: Vec<String>` для отслеживания подсказок директорий в `AppState`.
- `src/app/update/editor.rs`:
  - Интеграция автодополнения директорий в поле `DIRECTORY_FIELD` формы события `EventForm`.
  - Обновление подсказок при вводе и подстановка дополнения по клавише `Tab`.
- `src/ui/popup.rs`:
  - Отображение подсказок директорий `[AUTO]: dir1/ dir2/` в футере редактора при активном поле директории.
- `src/main.rs`:
  - Проверка аргументов командной строки при старте и запуск CLI-сценариев или полноэкранного TUI.

## 3. Сценарии работы

### 3.1. `rutendar --list [day|week|month]`
- Запускается в обычном потоке терминала (inline viewport, 8-10 строк).
- Строка поиска для фильтрации по заголовку, тегам и описанию.
- Переключение периода (`Tab` / `← / →`): День / Неделя / Месяц.
- Выбор элемента стрелками `↑ / ↓`.
- По `Enter`: виджет очищается, а выбранное событие выводится в терминал в виде подробной карточки с рамкой, цветами, описанием и ссылками.
- По `Esc` / `Ctrl+C`: отмена без вывода.

### 3.2. `rutendar --add`
- Интерактивный пошаговый опрос (название, дата, время, важность, теги, папка, описание).
- При вводе тегов `Tab` дополняет тег из базы.
- При вводе папки `Tab` дополняет директорию из файловой системы.
- Сохранение события в SQLite базу данных и вывод подтверждения.

### 3.3. Автодополнение в TUI (`rutendar`)
- В форме создания/редактирования события:
  - В поле `TAGS`: подсказки в футере, дополнение по `Tab`.
  - В поле `DIRECTORY`: подсказки папок в футере, дополнение по `Tab` с раскрытием `~`.
