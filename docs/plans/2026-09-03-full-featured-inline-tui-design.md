# Дизайн: Полноценный компактный Inline-режим Rutendar

## 1. Обзор и цели

Цель — переработать inline-режим `rutendar` в полноценный, компактный и интерактивный терминальный интерфейс (`ratatui::Viewport::Inline`), запускаемый по умолчанию при вводе команды `rutendar` в терминале.

### Ключевые возможности:
1. **Запуск по умолчанию на Сегодня**: при вызове `rutendar` без параметров прямо в текущей строке терминала открывается компактный 13-строчный виджет сегодняшнего дня (сохраняя историю командной строки и не переключаясь на альтернативный экран).
2. **Красиво обработанный вывод в терминал**:
   - По нажатию `Enter` на выбранном событии — вывод детальной карточки в рамке со ссылками, тегами, директорией и описанием.
   - По нажатию `p` — вывод полной замкнутой сводки дня (все события с временной шкалой + блок задач).
3. **Навигация и режимы**:
   - Вкладка **«День»** (`1`): детальный просмотр выбранной даты, листание дней стрелками `←`/`→`, возврат на сегодня по `t`, переключение статуса задач по `Space`.
   - Вкладка **«Неделя»** (`2`): обзор событий на 7 дней со сгруппированными заголовками дат.
   - Вкладка **«Поиск»** (`3` или `/`): мгновенный живой поиск по событиям, описанию и тегам.
4. **Быстрое добавление событий** (`a`): вызов пошагового мастера с автодополнением и предзаполненной датой текущего дня, с последующим возвратом в обновленный виджет.
5. **Бесшовный переход в полный TUI** (`F` или `Shift+T`): закрытие inline-виджета и мгновенное открытие полноэкранного календаря на альт-экране.
6. **Прямой запуск полного TUI из командной строки**: команда `rutendar --full` (или `--tui`, `tui`).

## 2. Архитектура и структура модулей

Следуя правилам модульности и чистой архитектуры (`AGENTS.md`), новый inline-режим выносится в отдельный подмодуль `src/cli/inline/`, не захламляя полноэкранный `App` и существующий `src/cli/list.rs`:

```text
src/
├── cli/
│   ├── inline/
│   │   ├── mod.rs       # Запуск терминала Viewport::Inline, цикл обработки клавиш и диспетчеризация
│   │   ├── state.rs     # Состояние InlineApp, вкладки InlineTab, фильтрация и навигация
│   │   └── render.rs    # Отрисовка вкладок, списков дня/недели/поиска и статус-бара
│   ├── format.rs        # Добавление format_day_summary к существующему format_event_card
│   ├── add.rs           # Переиспользование пошагового создания событий
│   └── mod.rs           # Парсинг аргументов CLI и диспетчеризация команд
├── main.rs              # Запуск inline по умолчанию и поддержка перехода в TUI
```

## 3. Точки входа CLI (`src/main.rs`, `src/cli/mod.rs`)

### Поведение `main.rs`:
```rust
let mut cmd = rutendar::cli::parse_cli_command(&args)?;

// Если аргументов нет, по умолчанию запускается интерактивный inline-режим
if cmd.is_none() {
    let (config, paths) = Config::load()?;
    let mut database = Database::open(&paths.database)?;
    match rutendar::cli::inline::run_inline(&mut database, &config, None)? {
        rutendar::cli::inline::InlineOutcome::OpenFullTui { initial_date } => {
            // Бесшовный переход в полноэкранный TUI
            let key_config = config.keys.clone();
            let mut app = App::new(database, config)?;
            if let Some(date) = initial_date {
                app.select_date(date);
            }
            let mut keymap = Keymap::new(&key_config);
            let mut tui = Tui::new()?;
            return event_loop(&mut tui, &mut app, &mut keymap);
        }
        rutendar::cli::inline::InlineOutcome::Exit => return Ok(()),
    }
}
```

### Флаги командной строки:
- `rutendar` — запуск интерактивного inline-режима (День: Сегодня).
- `rutendar --full`, `rutendar --tui`, `rutendar tui` — прямой вход в полноэкранный TUI.
- `rutendar --list [day|week|month]` — алиас запуска inline-режима с предварительным выбором вкладки/периода.

## 4. Модель данных и состояние (`src/cli/inline/state.rs`)

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum InlineTab {
    Day,
    Week,
    Search,
}

pub enum InlineOutcome {
    Exit,
    OpenFullTui { initial_date: Option<NaiveDate> },
}

pub struct InlineApp {
    pub tab: InlineTab,
    pub current_date: NaiveDate,
    pub selected_idx: usize,
    pub query: String,
    pub day_events: Vec<EventOccurrence>,
    pub day_tasks: Vec<Task>,
    pub week_events: Vec<EventOccurrence>,
    pub search_results: Vec<EventOccurrence>,
}
```

### Методы `InlineApp`:
- `new(today: NaiveDate, initial_tab: InlineTab) -> Self`: инициализация начальным состоянием.
- `reload_day(&mut self, db: &Database)`: загрузка событий и задач на `current_date`.
- `reload_week(&mut self, db: &Database)`: загрузка событий на неделю, содержащую `current_date`.
- `reload_search(&mut self, db: &Database)`: фильтрация событий по запросу `query`.
- `next_day(&mut self, db: &Database)` / `prev_day(&mut self, db: &Database)`.
- `today(&mut self, db: &Database)`: возврат к сегодняшнему дню.
- `toggle_selected_task(&mut self, db: &Database)`: переключение статуса задачи при наведении на неё.

## 5. Визуальный макет и отрисовка (`src/cli/inline/render.rs`)

Виджет занимает фиксированную высоту **13 строк** в стандартном потоке вывода терминала:

### Структура строк:
1. **Строка 1 (Шапка)**:
   - Вкладки: `[ 1 ДЕНЬ ]  2 НЕДЕЛЯ   3 ПОИСК`
   - Правая часть: `📅 Четверг, 03.09.2026 (F: Полный TUI · q: Выход)`
2. **Строка 2 (Контекст)**:
   - В режиме **День**: `Дата: ← 03.09.2026 (Сегодня) →  ·  3 события, 1 задача`
   - В режиме **Неделя**: `Неделя 36 (01.09 — 07.09.2026) · 12 событий`
   - В режиме **Поиск**: `🔍 Поиск: [запрос█]  (найдено: 5)`
3. **Строки 3–11 (Область контента)**:
   - В режиме **День**:
     - События с маркером `▸`, важностью (`!`, `•`, `·`), временем (`10:00 — 11:30`), названием и тегами.
     - Разделитель задач `── Задачи на день ──` и список задач `[ ]` / `[x]`.
   - В режиме **Неделя**:
     - События на 7 дней с префиксами дат (`[Пн 01.09] 10:00 Название`).
   - В режиме **Поиск**:
     - Найденные события с датой, временем и тегами.
4. **Строка 12 (Строка действий / подсказок)**:
   - `[↑/↓] Навигация  [Enter] Карточка  [p] Сводка дня  [a] Добавить  [Tab/1/2/3] Вкладка`

## 6. Форматирование красивого вывода (`src/cli/format.rs`)

### 1. Вывод карточки события (`Enter`):
Используется существующая функция `format_event_card(&event)`:
- Цветная плашка важности.
- Дата, день недели, время, повторяемость.
- Заголовок, теги, директория, описание и список ссылок.

### 2. Вывод красивой сводки дня (`p`):
Новая функция `format_day_summary(date, &[EventOccurrence], &[Task]) -> String`:
- Замкнутая двойная или одинарная рамка с закругленными углами (`╭─ 📅 День, DD.MM.YYYY ─╮`).
- Блок расписания с цветовой дифференциацией важности и временных интервалов.
- Блок задач с чекбоксами статуса.
- Нижняя граница рамки (`╰────────────────────────╯`).

## 7. Горячие клавиши

| Клавиша | Контекст | Действие |
|---|---|---|
| `Tab` / `BackTab` | Любой | Циклическое переключение вкладок: День ↔ Неделя ↔ Поиск |
| `1`, `2`, `3` | Вне ввода поиска | Прямой переход: 1 — День, 2 — Неделя, 3 — Поиск |
| `←` / `→` (или `h` / `l`) | Вкладка «День» | Переход на предыдущий / следующий день |
| `t` | Вкладка «День» | Быстрый переход на Сегодня |
| `↑` / `↓` (или `k` / `j`) | Любой | Перемещение курсора выбора (`▸`) по списку |
| `Space` | На задаче дня | Переключение статуса задачи `[ ]` ↔ `[x]` |
| `Enter` | Любой | Вывод подробной карточки выбранного элемента в `stdout` и выход |
| `p` | Любой | Вывод красивой полной сводки дня в `stdout` и выход |
| `a` / `+` | Вне ввода поиска | Запуск интерактивного мастера добавления нового события |
| `F` (или `Shift+T`) | Вне ввода поиска | Бесшовный переход в полноэкранный TUI |
| `q` / `Esc` / `Ctrl+C` | Любой | Чистый выход в шелл без вывода |

## 8. Тестирование и верификация

1. **Модульные тесты**:
   - `state.rs`: переключение вкладок, навигация по дням, пагинация/скроллинг, фильтрация поиска.
