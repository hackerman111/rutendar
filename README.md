# 📅 Rutendar

> **Быстрый, легковесный и функциональный локальный терминальный календарь и менеджер задач, написанный на Rust.**

[![Rust](https://img.shields.io/badge/Rust-1.80%2B-orange.svg)](https://www.rust-lang.org/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

`Rutendar` сочетает мощь полноэкранного терминального интерфейса (TUI на [Ratatui](https://github.com/ratatui/ratatui)) с Vim-навигацией и удобный CLI для мгновенного добавления событий, ведения списка дел (To-Do) и экспорта/импорта расписания между устройствами.

---

## 🌟 Основные возможности

- 📆 **4 режима отображения календаря**: Неделя (`Week`), День (`Day`), Месяц (`Month`), Год (`Year`).
- ☑️ **Задания (To-Do) с чекбоксами**: Задачи со статусом `[ ]` / `[x]`, сроками и приоритетами. Мгновенное переключение выполнения по нажатию `Space` во всех режимах!
- 🔍 **Всплывающее меню дня в Месяце (`o`)**: Наведите курсор на любой день в месяце и нажмите `o`, чтобы открыть компактное превью со всеми делами и задачами этого дня, переключать их по `Space` или открывать.
- 💬 **Интерактивное Inline-меню задач (`rutendar --task`)**: 10-строчное всплывающее меню прямо в командной строке для быстрого просмотра, поиска, фильтрации и выполнения дел.
- ⚡ **CLI для автоматизации и скриптов**: Добавление событий и задач одной строкой через терминал.
- 🔄 **Повторяющиеся события**: Ежедневные, еженедельные (с выбором дней недели), интервальные события с возможностью редактирования отдельных повторений.
- 🏷️ **Теги и поиск (Agenda)**: Полнотекстовый поиск по расписанию, фильтрация по тегам, важности и типам с автодополнением `#тегов`.
- 📁 **Связь с файловой системой**: Привязка локальной папки к событию с автодополнением путей при вводе и открытие шелла в ней по нажатию `c`.
- 🔗 **Ссылки и избранные URL**: Прикрепление веб-ссылок к событиям и заметкам, быстрый переход в браузер (`o`) или копирование в буфер обмена (`y`).
- 💾 **Экспорт и импорт базы данных**: Безопасный перенос расписания между устройствами с проверкой целостности и автоматическим созданием бэкапов.

## 🚀 Установка и сборка

### Требования
- Установленный [Rust / Cargo](https://rustup.rs/) (версия 1.80 или новее).
- SQLite3 (библиотека линкуется автоматически).

### Сборка из исходников
```bash
git clone https://github.com/your-username/rutendar.git
cd rutendar

# Сборка оптимизированного бинарника
cargo build --release

# Установка в систему (опционально)
cargo install --path .
```

Бинарный файл будет доступен в `target/release/rutendar` (или в `~/.cargo/bin/rutendar` при установке через `cargo install`).

## 🖥️ Использование в терминале (CLI)

Rutendar можно использовать как полноценный TUI, так и через быстрые команды терминала:

### 1. Полноэкранный TUI
```bash
rutendar
```
Открывает интерактивный календарь (по умолчанию стартует в режиме недели).

---

### 2. Задания (Tasks / To-Do)

#### Интерактивное inline-меню:
```bash
rutendar --task
# короткий алиас:
rutendar -t
# или:
rutendar task
```
Открывает компактное меню в терминале:
- `Space` — переключить выполнение задачи (`[ ]` ↔ `[x]`).
- `Tab` — переключение фильтров: **[ Активные ] [ Все ] [ Выполненные ]**.
- `j` / `k` (или `↓` / `↑`) — навигация по списку.
- `a` — быстро создать задание прямо в меню.
- `d` / `x` — удалить выбранное задание.
- Ввод любого текста — мгновенная фильтрация по названию и описанию.
- `Esc` / `q` — выход.

#### Однострочные команды через флаги:
```bash
# Добавить новое задание
rutendar --task-add "Сдать лабораторную работу" --date tomorrow --importance high
rutendar -t -a "Купить продукты" -d today --desc "Молоко, хлеб, чай"

# Отметить задачу выполненной (или вернуть в активные) по ID:
rutendar --task-toggle 1
rutendar --task-done 1

# Посмотреть список задач в терминале:
rutendar --task-list today   # задачи на сегодня
rutendar --task-list all     # все активные и завершенные задачи
```

---

### 3. События календаря (Events)
```bash
# Добавить событие из терминала
rutendar --add --title "Встреча команды" --date today --time 14:00-15:00 -i normal --tags "#работа"

# Просмотр событий
rutendar --list [day|week|month]
rutendar -l
```

---

### 4. Заметки и экспорт в Markdown (Notes)

#### Интерактивное inline-меню заметок:
```bash
rutendar --notes
# короткий алиас:
rutendar -n
# или:
rutendar notes
```
Открывает 10-строчное всплывающее меню заметок:
- `Tab` / `Shift+Tab` — переключение фильтра периодов: **[ День ] [ Неделя ] [ Месяц ] [ Все ]**.
- `Space` — отметить / снять выбор конкретной заметки для экспорта (`[*] / [ ]`).
- `a` — выбрать все заметки в текущем фильтре.
- `e` — **экспортировать** отмеченные заметки (или все в текущем фильтре, если ни одна не выбрана) в файл Markdown.
- `j` / `k` (или `↓` / `↑`) — навигация по списку.
- Ввод любого текста — поиск по заголовку и содержимому.
- `Esc` / `q` — выход.

#### Мгновенный вывод заметок в терминал (Daily / Weekly):
```bash
# Вывести в консоль все заметки на сегодня:
rutendar daily

# Вывести в консоль все заметки на текущую неделю:
rutendar weekly

# Вывести заметки на конкретный день (вчера, завтра или дата DD.MM.YYYY):
rutendar daily yesterday
rutendar daily 31.08.2026
```

#### Быстрый экспорт заметок через CLI:
```bash
# Экспорт всех заметок в Markdown файл:
rutendar --export-notes all
rutendar --export-notes all --file ~/my_notes.md

# Экспорт заметок за сегодня / неделю / месяц:
rutendar --export-notes day
rutendar --export-notes week
rutendar --export-notes month

# Вывод содержимого Markdown в консоль (stdout):
rutendar --export-notes today --stdout
rutendar -n -e week --stdout
```

---

### 5. Экспорт и импорт расписания
Вы можете выгрузить базу данных в отдельный файл (например, чтобы отправить расписание на ноутбук или сделать бэкап):

```bash
# Экспорт базы данных:
rutendar --export ~/rutendar_backup.db
# или коротко:
rutendar -e

# Импорт базы данных на другом компьютере:
rutendar --import ~/rutendar_backup.db
# с принудительным подтверждением перезаписи:
rutendar -i ~/rutendar_backup.db -f
```
> **Безопасность:** перед импортом `Rutendar` автоматически проверяет файл на целостность (`PRAGMA integrity_check`) и создает резервную копию текущей базы с временной меткой (`.bak`).

## ⌨️ Горячие клавиши в TUI

### Навигация
| Клавиши | Действие |
|:---|:---|
| `h` / `j` / `k` / `l` (или стрелки) | Перемещение: влево, вниз, вверх, вправо |
| `n` / `N` | Следующий день / предыдущий день (+1 / -1) |
| `gg` / `G` | В начало списка / в конец списка |
| `Ctrl+d` / `Ctrl+u` | Прокрутка страницы вниз / вверх |
| `Tab` / `Shift+Tab` | Переключение панелей (в дне) / режимов календаря |
| `g t` | Перейти к сегодняшнему дню (`Today`) |
| `g d` | Ввести дату для быстрого перехода (`Go to date`) |

### Режимы календаря
| Клавиша | Режим |
|:---|:---|
| `w` | **Неделя** (`Week`) — 7 дней с расписанием событий и задач |
| `D` | **День** (`Day`) — подробный вид дня, заметки и ссылки |
| `m` | **Месяц** (`Month`) — календарная сетка месяца |
| `Y` | **Год** (`Year`) — обзорный годовой календарь |

### Задания и события
| Клавиша | Действие |
|:---|:---|
| `Space` | **Отметить / снять выполнение задания (`[ ]` ↔ `[x]`)** |
| `T` | **Создать новое задание (To-Do) на выбранный день** |
| `a` | Создать новое событие или заметку |
| `e` / `r` | Редактировать выбранное событие или заметку |
| `d` / `x` | Удалить выбранный элемент |
| `p` | Изменить уровень важности (`None` / `Low` / `Normal` / `High`) |
| `o` | **В Месяце:** открыть превью дня со всеми делами / **В ссылках:** открыть URL в браузере |
| `y` | Скопировать URL ссылки в буфер обмена |
| `c` | Открыть shell в рабочей директории события |
| `Enter` | Выполнить действие / переключить задание / открыть редактор |
| `Esc` | Закрыть модальное окно / шаг назад |

### Поиск и повестка дня (Agenda)
| Клавиша | Действие |
|:---|:---|
| `/` | Открыть панель поиска и повестки дня (`Agenda`) |
| `t` | Панель ближайших событий (`Upcoming`) |
| `f` | Переключить фильтр даты (День → Неделя → Месяц → Все) |
| `R` | Фильтр по типу элемента (Все → Только события → Только заметки) |
| `i` | Фильтр по важности |
| `s` | Сортировка (по времени / по важности) |
| `[` / `]` | Выбор тега в списке доступных тегов |
| `Space` (в поиске) | Включить/выключить фильтрацию по выбранному тегу |
| `X` | Удалить выбранный тег из базы данных |

### В редакторе
- `Tab` / `Shift+Tab` — переключение между полями формы.
- `Ctrl+S` — сохранить изменения.
- `Ctrl+L` (в форме события) — открыть банк избранных ссылок.
- `?` — открыть справку по горячим клавишам.
- `q` — выйти из приложения.

## 🗄️ Расположение данных

По умолчанию `Rutendar` хранит базу данных SQLite и конфигурацию в стандартных каталогах вашей операционной системы:

- **Linux / macOS**: `~/.local/share/rutendar/rutendar.db`
- **Конфигурация**: `~/.config/rutendar/config.toml`
